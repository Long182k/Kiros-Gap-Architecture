# Frontend Requirements: Career Gap Architect

## 1. Overview
The frontend is a modern, responsive web application built with **Next.js 16**. It provides an intuitive interface for users to upload their resumes, paste job descriptions, and view detailed gap analysis results generated by AI.

## 2. Technical Stack
*   **Framework:** Next.js 16 (App Router)
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS 4
*   **UI Components:** Shadcn/UI (Radix Primitives)
*   **State Management:** React Query (TanStack Query) v5
*   **Icons:** Lucide React
*   **Validation:** Zod + React Hook Form
*   **Charts:** Recharts

## 3. Core Features

### A. Analysis Input
*   **Resume Upload:** Supports PDF file upload.
*   **Job Description:** Text area for pasting JD.
*   **Validation:** Ensures both inputs are present before submission.

### B. Real-time Polling
*   Since analysis is asynchronous, the frontend polls the backend status endpoint (`GET /api/v1/analysis/:jobId/status`) every few seconds.
*   Displays a loading state/progress bar while `status` is `PENDING` or `PROCESSING`.
*   Redirects to Results page upon `COMPLETED`.

### C. Visual Results Dashboard
*   **Score Gauge:** Visual representation of the match score (0-100).
*   **Missing Skills:** categorized lists (High/Medium/Low importance).
*   **Learning Path:** Step-by-step actionable guide.
*   **Interview Prep:** AI-generated questions.

### D. History
*   Users can view past analyses (stored in local storage or fetched from backend if auth exists).

## 4. Project Structure (`src/app`)
*   `page.tsx`: Landing page + Input form.
*   `results/[id]/page.tsx`: Detailed analysis view.
*   `history/page.tsx`: User's analysis history.
*   `layout.tsx`: Root layout with Providers (QueryClient, Theme).
*   `globals.css`: Tailwind directives and theme variables.

## 5. Environment Variables
*   `NEXT_PUBLIC_API_URL`: URL of the backend API (e.g., `https://api.example.com` or `http://localhost:3001`).
